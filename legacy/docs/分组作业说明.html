作业要求

1.1 作业背景

本实践以“AI你画我猜”为主题，使用公开涂鸦数据训练图像识别模型。通过模型训练、结果分析、简单调参和对照研究，理解深度学习模型如何从样本中学习、如何评价识别表现，以及数据与预处理对结果的影响。

每组3—4人，使用普通电脑CPU即可完成基础任务。训练流程已封装为函数和操作面板，无需先掌握完整训练代码。允许使用AI辅助编程、实验设计、结果解释和报告写作；小组应核查关键建议，并依据真实实验形成研究结论。本作业以小组实验报告为主要评分材料。

1.2 实践任务

  1. 完成初始实验。 按Notebook第1—5部分运行默认MLP，查看训练与验证曲线、各类别表现和错误样例，并使用自绘图片进行识别。
  2. 开展对照研究。 提出一个具体问题，在第6部分至少完成一次有目的的改动实验。初始实验可作为参照，报告须说明预期、修改条件和固定条件。
  3. 分析结果。 用曲线、指标和典型样例解释差异。结果未改善或差异不明显时，应说明可能原因与证据局限。
  4. 核查与讨论。 记录至少一条影响实验设计或结论的关键AI建议，说明核查方法与实际结果；记录一次实质性小组讨论、成员贡献及个人反思。

基础研究可选择学习率、训练轮数、网络大小等，自主确定合理研究问题。CNN、扩展训练、正则化、挑战评价、照片预处理和自定义模型均为可选方向，各路线适用相同评分标准。基础研究路线可获得满分，复杂模型、更多算力或更高准确率不自动加分。

1.3 实验报告

使用随包的报告模板.docx填写一份小组报告，按以下顺序组织。各部分应完整呈现，缺项影响对应评分。

（一）标题与基本信息

填写报告题目、小组编号、成员姓名与学号、日期。题目可体现本组研究问题。

（二）研究问题与预期

说明研究内容、选题理由和运行前的预期。问题应具体，能够通过本组实验进行检验。

（三）实验设置与对照设计

说明使用的模型、训练资料、主要参数和操作过程；列出参照与改动实验，注明修改条件与固定条件。完整参数可查阅实验TXT，正文保留与研究问题有关的信息。

（四）实验结果与分析

展示真实运行结果，选取少量关键曲线、类别指标或错误样例。每幅图均应有图题，并说明观察到的现象、支持的判断与可能的其他解释。分析至少两个类别，或结合典型错误说明模型的识别特点。截图与指标不能替代文字分析。

（五）关键AI互动与核查

至少保留一条关键互动：AI工具、关键输入、建议摘要、采用或修改的内容、核查方法、实际结果。可使用清晰截图或准确摘录，正文仅呈现与研究有关的内容，无需提交完整聊天记录。评价依据核查质量，不按互动次数评分。

（六）小组讨论与成员贡献

记录讨论议题、不同观点或方案、验证过程和决策理由。观点一致时如实说明。每名成员填写实际承担的工作及简短反思，体现真实协作过程。

（七）实验总结与局限

回答最初研究问题，说明对模型训练、基础调参、结果评价和AI建议核查的理解，分析结论适用条件、证据不足之处及后续验证方向。

报告应独立呈现上述过程与分析，实验附件作为补充。正文建议2—4页，可据研究内容合理调整，不按页数评分。

1.4 统一格式要求

报告以Word文档（.docx）提交，使用随包模板。模板内的提示应替换为本组内容；报告正文不能由整页截图、手写照片或实验日志替代。

1.5 提交要求

主文件： 小组编号_你画我猜报告.docx。报告为主要评分依据，应完整呈现关键设置、真实结果与本组分析。报告末尾附件：应包括实验的具体步骤，包含选定的参照与改动实验的TXT、模型及本组程序，用于补充核查。

提交前检查：报告已填写，结构与格式完整；参照与改动记录齐全，指标与附件一致；包含AI核查、小组讨论和各成员贡献。截止时间与提交平台以教师通知为准。

1.7 数据与学术规范

数据标签固定为猫、兔子、鸟、鱼、苹果、香蕉、蛋糕、甜甜圈。训练、基础验证与挑战来源按课程划分使用；验证数据及其变换不得加入训练。验证集可公开分析和用于调参，反复调参后的成绩不应称为独立测试成绩。

挑战中的偏移、加粗和遮挡为合成处理，不代表真实照片。使用自绘图片改进方法时，应另取一批图片评价改进。模型只识别八类，输出分数不构成正确性保证。

报告、实验记录、AI互动与成员贡献均须真实。不得抄袭、伪造结果或以未核查的AI生成内容替代本组研究。使用AI整理文字时，小组仍须核对内容并形成自己的分析。

1.8 运行与记录说明

环境安装、数据来源与调用方法见实验指南。每次训练自动生成实验记录.txt；比较功能生成实验汇总.txt。可将这些文字连同研究问题提供给AI，要求核对变化的条件、分析证据并提出可执行的核查方法。模型权重和公共数据不作为文字对话的必要输入。
